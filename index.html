    How to read this

    • Solis AI (actual). What really happened, priced from the inverter's own counters of grid import, export and battery use.
    • Our software (replay). What our planner would have done at every half hour, using only the solar and house forecasts it had saved at that moment. It never sees what happens next. It is a replay against real conditions, so battery effects we don't model can make a real run differ a little.
    • Predbat (replay). Predbat's real planner, run on the same saved forecasts and prices at every half hour, with its default settings. Its first action is applied to the real day. It isn't Predbat running live on Dad's system, and it is scored once a day, so it appears on finished days only, not on today's scoreboard.
    • Perfect hindsight. The best schedule possible if the whole day were known in advance. Nobody can reach it; it shows how much was on the table.
    • Plain overnight fill. A basic inverter that fills the battery in the cheap window and then just uses it. A yardstick for how smart Solis AI is being.
    • All four are costed the same way: money for grid power, plus battery wear, with the energy left in the battery at the end valued so a run that ends fuller isn't punished.
    • Export is off, so none of the four assumes selling to the grid.
